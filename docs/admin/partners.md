# قسم Partners (الشركاء العالميون)

## فكرة عامة

هذا القسم مخصص لإدارة **الشركاء والمصنعين العالميين** الذين تمثلهم الشركة كوكلاء معتمدين. يعرض القائمة الرسمية للعلامات التجارية والمصنعين الذين تتعامل معهم الشركة، مع ربط كل شريك بالأقسام الطبية والمنتجات المرتبطة به.

يُستخدم الشركاء في عدة أماكن:
- **الصفحة الرئيسية**: شريط متحرك (Marquee) يعرض شعارات الشركاء مع رابط لصفحة منتجاتهم
- **صفحة الشركاء العامة** (`/partners`): عرض تفصيلي لكل شريك مع وصفه وتخصصاته
- **صفحة المنتجات**: فلترة المنتجات حسب الشريك المصنع

## مهام القسم

- **إدارة قائمة الشركاء**: إضافة وتعديل وحذف الشركاء والمصنعين العالميين
- **ربط الشركاء بالأقسام الطبية**: تحديد أي departments طبية يرتبط بها كل شريك
- **إدارة الشعارات**: رفع شعار كل شريك وعرضه في الواجهات العامة
- **تحديد ترتيب العرض**: التحكم بترتيب ظهور الشركاء في الصفحة الرئيسية والواجهات
- **تفعيل/إيقاف العرض**: إخفاء شريك مؤقتاً دون حذفه
- **الربط بالمنتجات**: كل منتج يمكن ربطه بشريك محدد (المصنع)

## شرح الواجهة

### 1. شريط العنوان والإحصائيات

أعلى الصفحة يظهر:
- عنوان **Partners** مع إجمالي عدد الشركاء (`Managing X global partners and manufacturers.`)
- **حقل البحث**: للبحث عن الشركاء بالاسم
- **زر Add Partner**: لفتح نافذة إضافة شريك جديد

### 2. جدول الشركاء

| العمود | الوصف |
|--------|-------|
| **Partner Details** | شعار الشريك + اسمه + رابط موقعه الرسمي (إن وجد) |
| **Status** | حالة التفعيل: **Active** (أخضر) أو **Inactive** (رمادي) |
| **Order** | رقم ترتيب العرض (#0, #1, #2, ...) |
| **Departments** | الأقسام الطبية المرتبطة بالشريك (تظهر 3 كحد أقصى مع "+X more") |
| **القائمة** (ثلاث نقاط) | Edit Partner / Delete Partner |

### 3. Pagination

أسفل الجدول يظهر ترقيم الصفحات وعرض عدد الشركاء الظاهرين من الإجمالي. لكل شريك 15 شريكاً في الصفحة.

### 4. نافذة إضافة/تعديل شريك (PartnerForm)

النموذج يحتوي على:

**بيانات أساسية:**
- **Partner Name**: اسم الشريك (مطلوب)
- **Website URL**: رابط الموقع الرسمي
- **Description (English)**: وصف الشريك بالإنجليزية
- **Description (Arabic)**: وصف الشريك بالعربية (يدعم RTL)

**الأقسام الطبية (Medical Departments):**
- قائمة Checkboxes لاختيار الأقسام المرتبطة بالشريك
- تظهر في شبكة 3 أعمدة مع اسم القسم بالإنجليزية والعربية

**إعدادات إضافية:**
- **Logo Image**: رفع شعار الشريك (صورة)
- **Active**: Checkbox لتفعيل/إيقاف عرض الشريك
- **Order**: رقم ترتيب العرض

## التكامل مع الواجهة العامة

- **PartnerGrid** (الصفحة الرئيسية): شريط متحرك يعرض شعارات الشركاء. عند النقر على شعار، ينتقل إلى صفحة المنتجات مع فلترة حسب الشريك
- **صفحة `/partners`**: عرض بطاقات تفصيلية لكل شريك مع الشعار والوصف والتخصصات ورابط الموقع الرسمي
- أسفل صفحة الشركاء يوجد **Trust Banner** بشعار "Global Network, Local Support"

## العلاقات

- `Partner → Department`: علاقة **Many-to-Many** عبر جدول `partner_department`
- `Partner → Product`: علاقة **One-to-Many** (الشريك لديه عدة منتجات)

## الصلاحيات

| الصلاحية | الوظيفة |
|----------|---------|
| `partners.view` | عرض قائمة الشركاء |
| `partners.create` | إضافة شريك جديد |
| `partners.edit` | تعديل شريك موجود |
| `partners.delete` | حذف شريك |

## هيكل قاعدة البيانات

جدول `partners`:

| الحقل | النوع | الوصف |
|-------|------|-------|
| `id` | bigIncrements | المعرف الفريد |
| `name` | string | اسم الشريك |
| `desc_en` | text (nullable) | الوصف بالإنجليزية |
| `desc_ar` | text (nullable) | الوصف بالعربية |
| `logo` | string (nullable) | رابط الشعار |
| `website_url` | string (nullable) | رابط الموقع الرسمي |
| `is_active` | boolean (default: true) | حالة التفعيل |
| `sort_order` | integer (default: 0) | ترتيب العرض |
