# قسم Services & Solutions (الخدمات والحلول)

## فكرة عامة

هذا القسم مخصص لإدارة **الخدمات والحلول المتكاملة** التي تقدمها الشركة. ينقسم إلى نوعين:
- **Services**: الخدمات الهندسية والتقنية (مثل الصيانة الوقائية والعلاجية، التدريب، الدعم الفني)
- **Solutions**: الحلول المتكاملة (مثل تخطيط وتجهيز المنشآت الصحية، إدارة سلسلة التوريد)

يظهر هذا القسم للزوار في:
- **صفحة `/services`**: عرض جميع الخدمات والحلول مع إمكانية طلب الخدمة
- **الصفحة الرئيسية**: في KeyHighlights يتم عرض بعض الخدمات

عند طلب الزائر لخدمة معينة عن طريق **Service Request Modal**، يتم:
1. إنشاء **Lead** جديد بنوع `service_request` ومصدر `website_services`
2. إرسال إشعار عبر البريد الإلكتروني وداخل النظام إلى جميع المسؤولين والتقنيين
3. يمكن متابعة الطلب في قسم **Leads Pipeline** في لوحة التحكم

## مهام القسم

- **إدارة الخدمات والحلول**: إضافة وتعديل وحذف الخدمات
- **تصنيف المحتوى**: تحديد ما إذا كان العنصر **Service** أم **Solution**
- **ترتيب العرض**: التحكم بترتيب ظهور الخدمات في الصفحة العامة
- **إدارة الصور**: رفع صورة لكل خدمة
- **اختيار الألوان**: تحديد لون مميز لكل خدمة من 8 ألوان مختلفة
- **تفعيل/إيقاف العرض**: إخفاء خدمة مؤقتاً دون حذفها

## شرح واجهة الإدارة

### 1. شريط العنوان

أعلى الصفحة يظهر:
- عنوان **Services & Solutions** مع وصف فرعي
- **زر Add Service**: لفتح نافذة إضافة خدمة جديدة

### 2. جدول الخدمات

| العمود | الوصف |
|--------|-------|
| **Title & Description** | عنوان الخدمة بالإنجليزية + مقتطف من الوصف |
| **Type** | علامة ملونة: **Service** (أخضر) أو **Solution** (أزرق) |
| **Order** | رقم ترتيب العرض |
| **Actions** | Edit (تعديل) / Delete (حذف) |

**حالة عدم وجود بيانات**: تظهر رسالة "No services or solutions added yet" مع أيقونة وزر لإضافة أول خدمة.

### 3. نافذة إضافة/تعديل خدمة (ServiceForm)

النموذج يحتوي على:

**بيانات أساسية:**
- **Type**: اختيار نوع العنصر (Service / Solution) من قائمة منسدلة
- **Sort Order**: رقم ترتيب العرض
- **Active**: Checkbox لتفعيل/إيقاف عرض الخدمة

**المحتوى (باللغتين):**
- **English Title**: عنوان الخدمة بالإنجليزية (مطلوب)
- **English Description**: وصف الخدمة بالإنجليزية (مطلوب)
- **Arabic Title**: عنوان الخدمة بالعربية (مطلوب)
- **Arabic Description**: وصف الخدمة بالعربية مع دعم RTL (مطلوب)

**الوسائط:**
- **Image**: رفع صورة الخدمة (jpg, png, webp - حد أقصى 2MB) مع معاينة بنسبة 1:1
- **Theme Color**: اختيار لون مميز من 8 خيارات: Emerald / Blue / Indigo / Amber / Purple / Rose / Sky / Teal

## التكامل مع الواجهة العامة

- **صفحة `/services`**: تعرض الخدمات (type=service) في شبكة بطاقات مع صورة وعنوان ووصف وزر "Request Service"، والحلول (type=solution) في قسم بخلفية داكنة مع وصف مختصر وزر "Request Solution"
- **ServiceRequestModal**: نافذة طلب الخدمة تحتوي على: الاسم، رقم الجوال، البريد الإلكتروني، المستشفى/المؤسسة، المسمى الوظيفي. بعد الإرسال تظهر رسالة نجاح ويتم إنشاء Lead ومتابعته في Leads Pipeline

## آلية طلب الخدمة

1. الزائر يضغط **Request Service** أو **Request Solution**
2. تظهر نافذة النموذج (ServiceRequestModal)
3. بعد تعبئة البيانات وإرسالها:
   - يتم إنشاء **Lead** في قاعدة البيانات بنوع `service_request` مع بيانات الخدمة المطلوبة في `metadata`
   - يتم إرسال **إشعار** (بريد إلكتروني + إشعار داخلي) إلى جميع المستخدمين من نوع `admin` و `technician`
4. يمكن للمسؤول متابعة الطلب من **Leads Pipeline**

## هيكل قاعدة البيانات

جدول `services`:

| الحقل | النوع | الوصف |
|-------|------|-------|
| `id` | bigIncrements | المعرف الفريد |
| `type` | string (default: 'service') | نوع العنصر: `service` أو `solution` |
| `title_en` | string | عنوان الخدمة بالإنجليزية |
| `title_ar` | string | عنوان الخدمة بالعربية |
| `description_en` | text | وصف الخدمة بالإنجليزية |
| `description_ar` | text | وصف الخدمة بالعربية |
| `image` | string (nullable) | رابط صورة الخدمة |
| `color` | string (nullable) | اللون المميز |
| `is_active` | boolean (default: true) | حالة التفعيل |
| `sort_order` | integer (default: 0) | ترتيب العرض |
